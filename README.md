# 校园网自动连接器（CampusConnector）

Windows 平台的校园网自动认证连接工具：支持有线 / Wi-Fi（含 hzpu、hzpu-st 等 SSID）自动登录与在线状态保持，解决校园网认证失败、反复重连、状态误判等常见问题。

> 本项目供个人学习与日常使用，请遵守所在学校校园网管理规定。

## 下载

- 最新版本包：仓库根目录的 `CampusConnector-v2.0.5-win-x64.zip`（或见 Releases 页）
- 下载后解压，双击运行 `校园网自动连接器.exe`

## 运行要求

- Windows 10 / 11（x64）
- .NET 8 Desktop Runtime（Windows 桌面运行时 8.x）
  - 如果程序打不开，请先安装：<https://dotnet.microsoft.com/download/dotnet/8.0>

## 快速开始

1. 解压 zip 到任意目录。
2. 运行 `校园网自动连接器.exe`。
3. 在设置页配置校园网账号与网络偏好（首选网络、备用 SSID、优先使用有线网络等），保存后程序自动认证并保持在线。

## 使用建议

- 想固定走网线：设置页打开「优先使用有线网络」。
- 想走 Wi-Fi：先拔掉网线，再点「立即连接」。
- 如果 Wi-Fi 是 hzpu 且一直失败，把首选网络改成 hzpu-st 试试。

## v2.0.5 更新日志（2026-10-21）

1. 修复「一直尝试连接」问题：本机有线网卡已认证在线时直接判定为「已连接」，不再每 15 秒循环检测（此前程序用 Wi-Fi 地址去认证收到 E2808，并误判为「账号在其他设备登录」）。
2. 修复设置页状态一直停在「设置已保存，正在尝试连接…」：保存后现在显示真实结果（已连接 / 失败原因）。
3. 已连接时不再每 5 秒刷新状态，改为 30 秒静默复检，界面不再闪烁。
4. 认证返回 E2808 且配置了备用 SSID 时，会提示改连备用网络（如 hzpu 认证失败而 hzpu-st 成功）。
5. 日志去重：不再每 16 秒重复写「检测到账号已通过有线在线」。

## 日志与问题排查

- 日志位置：`%LOCALAPPDATA%\HZPULink\logs\app-YYYYMMDD.log`
- 反馈问题时请附上当天日志，其中包含认证服务器的返回内容，便于定位。
- 常见错误码：
  - `E2808`：找不到匹配的上网策略。多因认证使用了错误的网卡地址或 SSID，可尝试切换备用 SSID（如 hzpu-st）或开启「优先使用有线网络」。
